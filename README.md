# DICH™ Streetwear

Sitio multipágina de DICH™ desarrollado con React, Vite y Bootstrap 5.

## Páginas

- `index.html`: inicio y destacados.
- `catalogo.html`: catálogo completo y vista rápida de productos.
- `lookbook.html`: historia de la marca y lookbook.
- `contacto.html`: formulario de contacto.

`categorias.html` y `dich_brutalist_streetwear_e_commerce.html` siguen disponibles como rutas alternativas.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
